# 留下的权利 / The Right to Stay

[中文](#中文) · [English](#english)

## 中文

### 第一次使用

点开 [中文译文](entry.zh.txt) 或 [英文原文](entry.txt) 阅读。若想保存纯文本，点文件页面上的 **Raw**，再用浏览器的保存功能。

一首关于停下和留下的英文短诗，以缝纫机和父亲的一件旧外套为场景。

[阅读中文版](entry.zh.txt) · [阅读英文原文](entry.txt)

### 本地运行

使用 Node.js 22.18 或更新版本。设置 `MAKEFUN_OUTPUT_DIR` 指向输出目录并运行 `node main.ts`，即可生成 `entry.txt`。

## English

### First use

Read the [Chinese translation](entry.zh.txt) or [English original](entry.txt). To save plain text, select **Raw** and save it from the browser.

An English micro-poem about the power to stop and stay, told at a sewing table with a father’s coat.

[English original](entry.txt) · [Simplified Chinese translation](entry.zh.txt)

### Run locally

Use Node.js 22.18 or newer. Set `MAKEFUN_OUTPUT_DIR` and run `node main.ts` to generate `entry.txt`.
